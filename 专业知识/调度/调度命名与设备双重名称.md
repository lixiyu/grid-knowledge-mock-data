# 调度命名与设备双重名称

工作票、操作票、缺陷单和巡视记录使用调度命名，并写清电压等级和设备编号，避免俗称。

| 调度名称 | 电压 | 说明 |
| --- | --- | --- |
| 江洲变 | 220kV | 城东片区电源 |
| 城东变 | 110kV | 江东线受电 |
| 临江变 | 110kV | 江临线受电 |
| 高新变 | 110kV | 东高线受电，临高线热备用 |
| 江东线 | 110kV | 江洲变—城东变 |
| 江临线 | 110kV | 江洲变—临江变 |
| 东高线 | 110kV | 城东变—高新变 |
| 临高线 | 110kV | 临江变—高新变，热备用 |
| 城东Ⅰ回 | 10kV | 城东变馈出 |

“1号主变”必须带变电站名称。城东变1号主变与江洲变1号主变不是同一台设备。
